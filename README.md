# 🏃 Exercício 1 – Torneio de Atletismo

## Enunciado

Barnabé, Gumercindo e Teodoro participaram das provas de:

* 100 metros rasos
* Salto em distância
* Arremesso de dardo

Cada participante obteve exatamente um primeiro lugar, um segundo lugar e um terceiro lugar.

Sabendo que:

* Gumercindo venceu Barnabé no salto em distância;
* Teodoro chegou atrás de Gumercindo no arremesso de dardo;
* Barnabé não chegou em primeiro nos 100 metros rasos.

Determine a colocação de cada participante em cada prova.

---

## Resolução

A partir das informações fornecidas, conclui-se que:

### 100 metros rasos

| Participante | Colocação   |
| ------------ | ----------- |
| Teodoro      | 🥇 1º Lugar |
| Barnabé      | 🥈 2º Lugar |
| Gumercindo   | 🥉 3º Lugar |

### Salto em Distância

| Participante | Colocação   |
| ------------ | ----------- |
| Gumercindo   | 🥇 1º Lugar |
| Teodoro      | 🥈 2º Lugar |
| Barnabé      | 🥉 3º Lugar |

### Arremesso de Dardo

| Participante | Colocação   |
| ------------ | ----------- |
| Barnabé      | 🥇 1º Lugar |
| Gumercindo   | 🥈 2º Lugar |
| Teodoro      | 🥉 3º Lugar |

---

## Resultado Final

| Participante | 100m Rasos | Salto em Distância | Arremesso de Dardo |
| ------------ | ---------- | ------------------ | ------------------ |
| Barnabé      | 2º         | 3º                 | 1º                 |
| Gumercindo   | 3º         | 1º                 | 2º                 |
| Teodoro      | 1º         | 2º                 | 3º                 |

Dessa forma, cada participante obteve exatamente uma medalha de ouro, uma de prata e uma de bronze, satisfazendo todas as condições do problema.


# 🛢️ Exercício 2 – Problema dos Barris

## Enunciado

João tem três barris. No barril A, que está vazio, cabem 8 litros. No barril B, 5 litros. No barril C, 3 litros. O objetivo é deixar os barris A e B com 4 litros cada e o barril C vazio.

## Resolução

### Estado Inicial

* Barril A = 0 L
* Barril B = 5 L
* Barril C = 3 L

### Passos

1. Despejar o conteúdo do barril C no barril A.
2. Transferir o conteúdo do barril B para o barril C até enchê-lo.
3. Despejar novamente o conteúdo do barril C no barril A.
4. Transferir o conteúdo do barril B para o barril C.
5. Transferir o conteúdo do barril A para o barril B até completá-lo.
6. Transferir o conteúdo do barril B para o barril C até enchê-lo.
7. Despejar o conteúdo do barril C no barril A.

### Resultado Final

* Barril A = 4 L
* Barril B = 4 L
* Barril C = 0 L

# 🚗 Exercício 3 – Troca de Pneu

## a) Trocar o pneu traseiro esquerdo

1. Abrir o porta-malas.
2. Pegar o estepe, o macaco e a chave de roda.
3. Encaixar a chave de roda nos parafusos do pneu traseiro esquerdo.
4. Desafrouxar os parafusos.
5. Posicionar o macaco na lateral esquerda do carro.
6. Erguer o veículo.
7. Retirar completamente os parafusos.
8. Retirar o pneu furado.
9. Instalar o estepe.
10. Recolocar os parafusos.
11. Baixar o veículo.
12. Apertar completamente os parafusos.

### Fluxo Resumido

```text
Início
 ↓
Abrir porta-malas
 ↓
Retirar ferramentas
 ↓
Afrouxar parafusos
 ↓
Erguer veículo
 ↓
Retirar pneu
 ↓
Instalar estepe
 ↓
Baixar veículo
 ↓
Apertar parafusos
 ↓
Fim
```

## b) Trocar o pneu verificando antes o estepe

1. Abrir o porta-malas.
2. Pegar o estepe, o macaco e a chave de roda.
3. Verificar se o estepe está em condições de uso.
4. Caso esteja adequado, continuar o procedimento.
5. Caso não esteja adequado, buscar assistência.
6. Realizar a troca do pneu seguindo os passos da situação anterior.

## c) Verificar qual pneu está furado antes da troca

1. Verificar todos os pneus do veículo.
2. Identificar se existe pneu furado.
3. Caso não exista, finalizar o procedimento.
4. Caso exista, identificar qual pneu será substituído.
5. Abrir o porta-malas.
6. Retirar estepe, macaco e chave de roda.
7. Verificar as condições do estepe.
8. Caso esteja adequado, continuar.
9. Caso contrário, buscar assistência.
10. Realizar a substituição do pneu identificado.
11. Finalizar o procedimento.

# 🔍 Exercício 1 – Interpretação de Algoritmo

## Enunciado

Considere o seguinte trecho de algoritmo:

```text
inteiro: X, Y;
real: Z;

leia(X);
escreva(X elevado ao cubo);

leia(Y);
escreva(X + Y);

Z ← X / Y;
escreva(Z);

Z ← Z + 1;

X ← (Y + X) mod 2;

escreva(X);
```

## Explicação

### inteiro: X, Y

Declara duas variáveis do tipo inteiro.

### real: Z

Declara uma variável do tipo real.

### leia(X)

Recebe um valor informado pelo usuário e armazena em X.

### escreva(X elevado ao cubo)

Exibe o valor de X elevado à terceira potência.

### leia(Y)

Recebe um valor informado pelo usuário e armazena em Y.

### escreva(X + Y)

Exibe a soma entre X e Y.

### Z ← X / Y

Realiza a divisão entre X e Y.

### escreva(Z)

Mostra o resultado da divisão.

### Z ← Z + 1

Incrementa o valor de Z em uma unidade.

### X ← (Y + X) mod 2

Calcula o resto da divisão da soma entre X e Y por 2.

### escreva(X)

Exibe o resultado final armazenado em X.

# Síntese Conceitual – Estruturas de Controle

As estruturas de controle governam o fluxo de execução das instruções em um algoritmo.

---

## 📋 Estrutura Sequencial

Consiste na execução linear e contínua dos comandos, seguindo a ordem em que foram escritos.

```text id="5sy0jl"
Início
 ↓
Comando 1
 ↓
Comando 2
 ↓
Comando 3
 ↓
Fim
```

---

## 🔀 Estruturas de Seleção (Condicionais)

Permitem que diferentes ações sejam executadas dependendo de uma condição.

### Simples (if)

Executa um bloco de código somente quando a condição for verdadeira.

```python id="y25xnn"
if idade >= 18:
    print("Maior de idade")
```

### Composta (if-else)

Oferece um caminho alternativo caso a condição seja falsa.

```python id="mduv9x"
if nota >= 7:
    print("Aprovado")
else:
    print("Reprovado")
```

### Encadeada (if-elif-else)

Permite avaliar múltiplas condições em sequência.

```python id="7z9jlwm"
if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")
```

### Múltipla Escolha (match-case / switch)

Avalia diretamente o valor de uma variável.

```python id="6cv9v4"
match opcao:
    case 1:
        print("Cadastrar")
    case 2:
        print("Consultar")
    case _:
        print("Opção inválida")
```

---

## 🔄 Estruturas de Repetição

São utilizadas quando uma ação precisa ser executada várias vezes.

### While

Repete enquanto uma condição permanecer verdadeira.

```python id="wdrr2x"
contador = 0

while contador < 5:
    print(contador)
    contador += 1
```

### For

Executa uma quantidade previamente conhecida de repetições.

```python id="6syuvk"
for i in range(5):
    print(i)
```

## Exercício 1 – Estrutura Sequencial

### Enunciado

Leia o valor da hora de trabalho, a quantidade de horas trabalhadas no mês e o percentual de desconto do INSS. Calcule e exiba o salário bruto, o desconto e o salário líquido.

```python id="1hrm6m"
horas_trabalhadas = float(input("Digite as horas trabalhadas: "))
valor_hora = float(input("Digite o valor da hora: R$ "))
percentual_inss = float(input("Digite o % de desconto do INSS: "))

salario_bruto = horas_trabalhadas * valor_hora
total_desconto = (percentual_inss / 100) * salario_bruto
salario_liquido = salario_bruto - total_desconto

print(f"Salário Bruto: R$ {salario_bruto:.2f}")
print(f"Desconto INSS: R$ {total_desconto:.2f}")
print(f"Salário Líquido: R$ {salario_liquido:.2f}")
```

## Exercício 2 – Seleção Composta e Encadeada

### Enunciado

Leia duas notas de um aluno, calcule a média e determine sua situação:

* Aprovado (≥ 7,0)
* Recuperação (entre 5,0 e 6,9)
* Reprovado (< 5,0)

```python id="l08o1v"
nota1 = float(input("Digite a 1ª nota: "))
nota2 = float(input("Digite a 2ª nota: "))

media = (nota1 + nota2) / 2

print(f"Média calculada: {media:.1f}")

if media >= 7.0:
    print("Situação: APROVADO")
elif media >= 5.0:
    print("Situação: RECUPERAÇÃO")
else:
    print("Situação: REPROVADO")
```

## Exercício 3 – Estrutura de Repetição com While

### Enunciado

Somar números inteiros informados pelo usuário até que um valor negativo seja digitado.

```python id="8xy4kl"
soma = 0

numero = int(input("Digite um número positivo (ou negativo para sair): "))

while numero >= 0:
    soma += numero
    numero = int(input("Digite o próximo número (ou negativo para encerrar): "))

print(f"A soma total dos números digitados é: {soma}")
```

num = int(input("Digite o número para gerar a tabuada: "))
